# Лабораторная работа: Бинарное дерево поиска (BST)

## Цель работы
Реализовать бинарное дерево поиска для хранения целых чисел с возможностью вставки, поиска и получения k-го минимального элемента через консольное меню.

## Описание задачи
Бинарное дерево поиска (BST) - это структура данных, где:
- Каждый узел содержит значение, ссылки на левого и правого потомка
- Для любого узла все элементы в **левом поддереве меньше** его значения
- Для любого узла все элементы в **правом поддереве больше** его значения
